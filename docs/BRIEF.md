# Candy Fusion 设计与开发 Brief

## 项目一句话

用左右键和掉落按钮，把晶莹圆润的水果糖果投入透明瓶子，通过物理碰撞与连续合成冲击最高分的横屏微信小游戏。

需求边界见 [PRD](PRD.md)，视频和截图见 [参考素材说明](references/README.md)。本文件描述目标体验，不预先锁定引擎或精确数值。

## 希望玩家感受到什么

容易上手，落点选择有意义；糖果落下有重量，碰撞时略带软弹，滚动能创造新的合成机会；连续合成清出空间时有惊喜，瓶口接近填满时有紧张感。

不要仅靠高弹性制造“热闹”：需要让物体最终能够稳定堆积。参考录像里的合成与明显位移同时发生，具体推力和运动规律需要原型调试，不能直接当作已测得的物理参数。

## 画面方向

- **颜色**：粉色、淡紫色为主，暖黄色高光；按钮与文字保持辨识度。
- **糖果**：圆形轮廓、透明外壳、厚实高光边缘，内部是水果切片或简化图案；不同等级同时用图案、颜色和尺寸区分。
- **瓶子**：透明材质、清楚的瓶壁与瓶底、适度高光，内部物体易于辨认。视觉轮廓与实际碰撞边界保持一致。
- **界面**：圆润、饱满、有糖果感；采用横屏三栏构图，让瓶子保持视觉中心。
- **动效**：合成瞬间的短暂放大、闪光、星星和适度位移；控制遮挡，玩家仍能看清糖果的位置。
- **正式资产**：原创糖果世界及装饰角色，不直接使用 DNF 角色、界面贴图、音效或视频中的消息横幅。

## 布局与操作

| 区域 | 内容与目的 |
| --- | --- |
| 左侧 | 得分、最高分、合成等级图，提供目标和规则提示 |
| 左下 | 左右圆润按钮，拇指可持续按住操作 |
| 中央 | 透明瓶子、待投放糖果与落点辅助线，保证主要观察空间 |
| 右侧 | 下一颗预览与掉落按钮，减少判断和操作距离 |
| 结算 | 本局成绩、最高分和再次挑战，层级简洁清楚 |

原录像的炸弹入口仅作参考；首版若不实现，应从正式界面移除，避免出现无效按钮。适配以保持瓶内玩法比例为优先，不直接拉伸画面；横屏刘海、安全区和触控范围需要真机确认。

## 实现关注点

- 优先验证微信小游戏兼容性，再选择渲染方案、引擎和二维物理库；当前没有最终技术选型。
- 将等级链、半径、分值、随机权重和物理参数配置化，便于试玩调节。
- 物理更新与渲染分离，使用稳定的物理时间步；处理切后台和恢复产生的时间跳变。
- 同一糖果在一轮接触处理中只能参加一次合成；物体创建、销毁和连锁事件需要明确顺序。
- 落点限制考虑当前糖果半径；对局、结算和重开明确管理输入及物理状态。
- 音效和震动可增强反馈，具体开关及默认设置在交互设计时确定。
- 当前无后端需求；未来公开发布所需的平台配置和流程另行补充。

## 建议交付顺序

1. **玩法原型**：简单圆形占位图，打通控制、物理、合成、计分、判输与重开。
2. **手感定稿**：测试尺寸梯度、投放节奏、堆积稳定性、连锁效果和临界判输，落实 PRD 待定项。
3. **视觉版本**：原创糖果资产、背景、按钮、合成特效及音效，保持物理轮廓一致。
4. **发布准备**：真机兼容与性能验证，素材授权检查，以及微信小游戏发布准备。

先通过能完整玩一局的原型确定体验，再扩展可选模式。
