# 微信好友体验与发布

## 当前状态（2026-10-28）

项目为微信**小游戏**，不是普通小程序页面。个人主体正式账号已完成注册，本机已配置正式 AppID，微信开发者工具成功上传 `0.1.0`（2026-10-28 10:15:28），后台已设为体验版。两位指定好友已绑定为体验成员，仅授予查看体验版权限；管理员无需重复绑定。用户已确认体验版可玩。尚未提交审核或公开发布。

体验二维码为临时交付文件，未纳入 Git；本次后台显示 2026-11-04 前有效，过期可在版本管理重新获取。本地 AppID 和开发工具私有配置也不提交。
当前构建约1.82 MiB；横屏；本地图片及音频，无自建服务器、登录、广告、支付、在线排行榜。最高分只保存在设备本地。运行游戏不依赖开发电脑或 Vite 服务，localhost 链接不能发给异地朋友使用。

## 先让朋友玩：体验版

1. 在自己的浏览器进入微信公众平台 <https://mp.weixin.qq.com/>，登录或注册对应的小游戏账号。开发工具登录与正式小游戏账号注册是两件事。
2. 如果已有账号，在后台的账号信息/开发设置中确认 AppID、主体类型和游戏类目。后台菜单名称可能调整，以实际页面为准。不要把普通小程序的 AppID 直接用于这个小游戏。
3. 将正式小游戏 AppID 写入本地配置 `wechat/project.local.config.json` 的 `appid` 字段，然后重新构建。也可通过 `WECHAT_APP_ID` 环境变量覆盖。无需提供 AppSecret。
4. 让开发工具登录的微信成为该账号管理员或具备上传权限的开发者。导入目录为项目下的 `dist/wechat`。
5. 在开发工具「上传」填写版本号 `0.1.0`，说明可使用下方草稿。上传成功后，在后台版本管理找到开发版本并设为体验版（具体可用入口取决于账号状态）。
6. 在后台成员管理添加朋友的**微信号**为体验成员，按页面提示完成验证，再分享体验二维码。不要授予朋友开发者/管理员权限。
7. 用至少一个非管理员的朋友账号实际扫码，确认能进入，再扩大邀请。体验成员的数量及账号资格以后台显示为准。

体验版面向受邀账号；公开给任意账号访问需要另行完成审核和发布。开发工具临时「预览」码不等于体验版二维码，也不等于正式发布。

## 构建与验收

```sh
npm run build
```

使用仓库固定的 Node 24.22.1。发布目录是 `dist/wechat`；`dist/web` 是独立浏览器版本。不要上传整个源代码仓库、参考视频、截图、生成原稿或开发工具私有配置。

体验版验收：受邀的非管理员账号扫码；左右长按及投放；连续合并；下方合并后上方自然下落；音效/音乐开关；切后台再回来；结束并重开；退出后最高分仍保留。当前构建通过不等于已完成这一轮跨账号验收。
