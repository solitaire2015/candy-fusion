## 能确认与不能确认的内容

录像可以支持横屏三栏布局、左右与掉落按钮、下一颗预览、逐级合成、积分、最高分及结束重玩的方向。顺序图可数出约 11 级，末级图案是西瓜。

录像未充分证明每级准确分值、掉落概率、瓶口宽限时长、最大等级合成结果或炸弹实际效果。这些应按 [PRD 的待定项](../PRD.md#6-待设计与试玩确定) 通过后续设计与试玩确定。
